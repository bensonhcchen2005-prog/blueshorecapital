Decision Flow Reference
1. Origination — scanner iterates the universe and runs every strategy; raw signals with score ≥ MIN_SIGNAL_SCORE (0.50) are logged as originated.
2. Stage-1 Gate — 11-rule ladder: symbol whitelist → strategy whitelist → score ≥ 0.65 → regime → open cap → notional cap → daily exposure → sector cap → quote staleness → earnings blackout → cash floor. First failure short-circuits with a canonical reason code.
3. Queue — ALLOW → written to live_shadow.jsonl (shadow) or live_pending_orders.json (live, awaiting approval).
4. Fill — paper system fills immediately via moomoo SIMULATE; live requires dashboard approval. All fills logged to signal_events.jsonl.
Signal ID: sha1(symbol|strategy|direction|minute)[:12] — deterministic, so events at any stage join cleanly by ID.
